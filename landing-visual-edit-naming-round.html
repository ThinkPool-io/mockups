What should the visual editing loop be called?

Five names that explain the feature before a visitor knows thinkpool’s vocabulary. Each direction is shown in the real Cascade and Review card context.

01 Direct and immediately clear
Recommended
Cascade

Split the work. Keep control.

A conductor investigates, sends defined slices to visible worker lanes, then collects and verifies what comes back.

Review

Make every result prove itself.

Reviewer lanes try to break the work before it lands. Builds, tests, evidence, and handoffs stay in the same room.

Visual edit

Edit the interface your agents built.

Open a verified preview, select an element on the page, and request the change. The coding lane updates the real source, rebuilds it, and returns fresh desktop and mobile proof.
