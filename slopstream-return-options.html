SlopStream navigation study

Ten cleaner ways back

Each option returns from About to the converter. The content is identical; only hierarchy and control treatment change.

01 Centered quiet pill
Best fit
SlopStream← Converter

Clear, compact, and still centered. It reads as a control without competing with the page.

02 Split header
SlopStreamConverter ↗

Familiar website navigation. Strong clarity, but breaks the fully centered composition.

03 Breadcrumb
SlopStream/About

Explains location and makes the product name the return action.

04 Home / About switch
HomeAbout

The clearest relationship between both pages. Slightly more interface than the product needs.

05 Utility strip
← Return to SlopStream

Unmissable and restrained. The full-width rule makes it feel structural.

06 Icon plus label
←Converter

A larger tap target with a plain label. More app-like than editorial.

07 Wordmark sublink
SlopStreamOpen converter ›

Very light and centered. Clearer than the current underlined back link.

08 Primary action
SlopStreamUse SlopStream

Strongest call to action. Useful if conversion matters more than keeping About quiet.

09 Outlined action
← Go to converter

Clear button affordance with less visual weight than the blue primary action.

10 Corner controls
←SlopStream×

Maximum space efficiency. The arrows need labels or tooltips for first-time visitors.
